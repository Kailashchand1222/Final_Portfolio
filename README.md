# 💼 My Portfolio

A personal portfolio website built with **React** and **Vite**, featuring smooth particle animations and a clean modern design.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| [React 18](https://react.dev/) | UI Framework |
| [Vite](https://vitejs.dev/) | Build Tool & Dev Server |
| [tsParticles](https://particles.js.org/) | Particle Background Animations |
| [React Toastify](https://fkhadra.github.io/react-toastify/) | Toast Notifications |

## ⚙️ Getting Started

### Prerequisites

- Node.js `v16+`
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Kailashchand1222/college-election-voting-system.git

# 2. Navigate into the project
cd react-portfolio

# 3. Install dependencies
npm install

# 4. Start the dev server
npm run dev
```

Open https://kailashchand1222.com.np/ in your browser.
